# Practice reports for two China-focused Agent Skills

This repository holds **reproducible practice reports** for two open-format Agent Skills:

| Report | Skill | What the run demonstrates |
| --- | --- | --- |
| [practice-culture-guide.md](practice-culture-guide.md) | [china-culture-guide](https://github.com/jackwangliang/china-culture-guide) | Live-search gate, premise check on a wrong causal claim, evidence tiers A/B/C, source-cluster check, and an honest record of a source that could not be verified |
| [practice-sourcing-clusters.md](practice-sourcing-clusters.md) | [china-sourcing-clusters](https://github.com/jackwangliang/china-sourcing-clusters) | Full 9-section Sourcing Route Card on a new product, cluster-vs-wholesale-market distinction, paste-ready Chinese queries, RFQ and verification pack |

Each report contains **input / process / output / verification** and a self-check list. Both runs were performed by the author's own agent on 2026-11-12; they are **self-tests, not third-party user cases**. Neither repository has external users yet, and no supplier, price, MOQ or transaction data appears in these reports.

Reproduce with `npx skills add jackwangliang/china-culture-guide` and `npx skills add jackwangliang/china-sourcing-clusters`.
